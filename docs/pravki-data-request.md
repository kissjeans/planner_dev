## 2. Колонки в борде задач

Зачем: делаю так, как вы описали. Карточка проекта, внутри таймлайн, в таймлайне подзадачи. Подзадачи будут падать отдельными строками в борд, у каждой свой исполнитель, даты и статус.

Чтобы бот заполнял строки, мне нужны точные названия колонок в вашем борде.

| Что бот пишет | Как называется колонка у вас |
|---|---|
| Название задачи | |
| Исполнитель | |
| Дата начала | |
| Дедлайн | |
| Статус | |
| Проект (связь с карточкой проекта) | |

Плюс:

- Ссылка на борд, куда класть задачи.
- Какие есть значения статуса и какой ставить новой задаче.
- Если колонки связи с проектом нет, скажите, можно ли её добавить. Без неё задачи не привяжутся к карточке.
- Интеграцию бота нужно подключить к этому борду (в Notion: три точки сверху, Connections, выбрать интеграцию).

Один момент честно. Сам встроенный таймлайн внутри карточки через API не создаётся, Notion такого не даёт. Делается один раз руками: настраиваете шаблон карточки проекта с нужным видом, дальше бот кладёт задачи и они сами появляются в таймлайне. Скажите, кто это настроит с вашей стороны, или я объясню по шагам.

## Про анализ брифа

Тут данных пока не прошу, нужно только определиться:

1. Как бриф попадает к боту? Файлом в чат, текстом, ссылкой на страницу в Notion?
2. Что должно получиться? Мой вариант: короткая выжимка (клиент, задача, сроки, бюджет), список противоречий, список чего не хватает. Кладу это в раздел «Бриф» в карточке проекта.

Пришлите пару реальных брифов и пример хорошего разбора, по ним настрою.

## Что уже сделал, данные не нужны

Пункт про безумные сроки закрыт, это была ошибка в коде, не в данных.

Задача «Дизайн презентации» это 2 дня внешнего дизайнера. Но у внешнего в базе стоит 0 часов в день (он вне команды), и расчёт делил 16 часов на эти нули, получалось 16 дней вместо 2. Плюс не учитывалось ожидание ответа клиента.

Что было и что стало на стандартном шаблоне:

| | было | стало |
|---|---|---|
| реальный план | 15 рабочих дней | 15 рабочих дней |
| что бот показывал | 27 рабочих дней, почти 5,5 недель | 18 рабочих дней, 3,6 недели |

Отсюда и брались те самые 5,5 недель. Починил, проверил тестами.

Про буфер, чтобы закрыть вопрос: буфер ровно 2 рабочих дня и только когда дедлайн не назвали. Если дедлайн назвали, бот ставит именно его. Никаких процентов от срока в боте нет.
