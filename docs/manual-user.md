# Руководство пользователя — бот-планировщик

Для команды и менеджера. Как пользоваться ботом в Telegram каждый день.

---

## Что это

Бот в Telegram, который автоматически раскладывает задачи проекта по людям и
дням: учитывает занятость, зависимости задач и дедлайн, считает план и
показывает, кто что и когда делает, и где будут перегрузы. Дублирует план в
Notion. Для «ручных» правок есть веб-доска (см. раздел «Админ-доска»).

Источник правды — база бота. Notion и чат — это поверхности отображения.

## Как начать

1. Найдите бота в командном чате (его уже добавили туда при настройке).
2. Отправьте `/start` — бот пришлёт короткую справку.
3. Меню команд доступно по кнопке «/» рядом с полем ввода.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и краткая справка |
| `/task <текст>` | Создать проект или задачу |
| `/load [имя]` | Показать загрузку команды на 14 дней (картинкой) |
| `/vacation <имя даты>` | Оформить отпуск / выходной |
| `/replan` | Пересчитать план по текущим данным |

Команды можно не печатать целиком: достаточно **упомянуть бота** (`@имя_бота`) и
написать запрос обычным текстом.

## Создание проекта

Отправьте бриф проекта одной командой `/task`. Укажите название, шаблон и (если
есть) дедлайн:

```
/task Новый проект "Альфа", шаблон standard, дедлайн 25 июня
```

- **Шаблон `standard`** — полный набор задач пресейла.
- **Шаблон `lite`** — урезанный набор (без части задач), когда сроки жмут.

Бот разворачивает шаблон в задачи, раскидывает их по людям и отвечает планом:
**кто → что → когда**, плюс предупреждения о перегрузах. Под планом — две кнопки:

- ✅ **Зафиксировать** — сохранить план (он становится «committed»).
- ✏️ **Правка** — внести изменения (см. ниже).

### Прямой и обратный режим

- **Прямой режим** (дедлайн задан) — бот строит план под дедлайн. Если дедлайн
  недостижим, бот так и говорит и предлагает рычаги: перейти на `lite`, добавить
  человека или сдвинуть дедлайн.
- **Обратный режим** (дедлайн не задан) — бот считает **самую раннюю** дату
  завершения по критическому пути и показывает её. В базу при этом ничего не
  пишется — это прикидка.

## Правки плана

Нажмите ✏️ **Правка** и напишите изменение обычным текстом, например:

```
убери задачу «Вычитка» из Альфы
```

Бот накапливает правки в новое предложение плана. Когда всё устраивает —
напишите «ок» (или нажмите ✅), чтобы зафиксировать итоговый вариант.

## Отдельная задача

Можно завести одиночную задачу вне шаблона — просто опишите её ботом
(название, кому, проект, срок). Бот заведёт задачу и (если подключён Notion)
добавит её строкой в базу задач.

## Загрузка команды

```
/load            — загрузка всей команды на 14 дней
/load Айгуль     — загрузка одного человека
```

Бот присылает картинку: занято против ёмкости по дням, перегрузы — красным.

## Отпуска и выходные

```
/vacation Айгуль 10-12 июня
```

Бот проставляет нерабочие дни и **пересчитывает план**, сдвигая её задачи так,
чтобы ничего не выпало и дедлайн не сорвался.

## Пересчёт плана

```
/replan
```

Пересобирает план по текущим данным (после изменений в людях/задачах/отпусках).

## Голосовые сообщения

Бот понимает голос. Чтобы он обработал голосовое:

- отправьте голосовое **в ответ (reply)** на сообщение бота, **или**
- сначала **упомяните бота** (`@имя_бота`) текстом, затем пришлите голосовое.

Бот расшифрует речь и выполнит запрос так же, как текст.

## Кто что может

Единый чат команды — единая зона прав (нет отдельного «только чтение»):

- **Любой участник командного чата** может создавать проекты, фиксировать и
  пересчитывать планы.
- **Известный участник команды** (с записью в базе) имеет те же права в личке с
  ботом.
- Посторонние вне командного чата игнорируются.

## Дневная сводка

Каждый рабочий день в **10:00 (Москва)** бот сам публикует в чат сводку:
загрузка команды и перегрузы.

## Связка с Notion

Если Notion подключён (см. инструкцию по интеграции):

- При создании проекта бот заводит **мастер-карточку** проекта: чеклист задач,
  пустой раздел «Бриф» и раздел «Идеи» (его команда заполняет руками).
- Когда задача отмечена выполненной, бот **ставит галочку** в чеклисте.
- Сброс плана — карточка архивируется.

Если Notion не подключён — бот работает как обычно, просто без этой синхронизации.

## Админ-доска (веб)

По адресу `http://<хост>:8000` доступна веб-доска для ручных правок:

- **Проекты** и их задачи,
- **Команда** (люди, роли, ёмкость),
- **Задачи** с исполнителями и сроками,
- **Журнал** (`/audit`) — кто, что и когда менял.

Доска не выставляется в публичный интернет — доступ через VPN/SSH-туннель.

## Ограничения текущей версии

- Сценарий **«что-если»** (моделирование без записи) в боте сейчас отключён.
- Ёмкость человека — **дневной потолок 8 ч**; перегрузы помечаются, но не
  блокируют план и не перебалансируются автоматически.
- Один процесс, одна команда, один чат (single-tenant).
